# mgscdc.github.io
Just a codec simulator like the patriots intended.

TL;DR

MGSCDEC (MGSCDC) is a built-in codec communicator inside a web that the operator can use to call codec receiver. Operator can use it directly here: https://suzuya-akari.github.io/mgscdc.github.io/
